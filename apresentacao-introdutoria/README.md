# Apresentação introdutória — UX, DX e AX

Esta é a versão recomendada para uma primeira conversa com a equipe. Ela usa
linguagem simples, um exemplo de loja online e introduz AX somente depois de UX,
DX e do conceito de agente.

- `index.html`: versão interativa e offline.
- `UX-DX-AX-INTRO.pdf`: versão para compartilhar/apresentar.
- `roteiro.md`: fala sugerida e explicação do material anterior.

Controles do HTML: setas ou espaço para navegar, `N` para notas e `F` para tela
cheia. O PDF pode ser impresso ou apresentado diretamente.

## Ordem recomendada dos materiais

1. Comece por esta apresentação introdutória.
2. Use a apresentação original como módulo avançado sobre medição.
3. Demonstre o laboratório apenas se houver tempo ou em uma segunda sessão.
